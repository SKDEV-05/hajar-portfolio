# Hajar Salmi portfolio

Bilingual Next.js App Router portfolio with 14 PDF-sourced projects, light/dark/system themes and optimized local artwork.

## Development

npm install
npm run dev

## Checks

npm run typecheck
npm run lint
npm run check:content
npm run build

Configure SITE_URL for production canonical URLs. Do not deploy changes without authorization.

V3 introduces an editorial portrait hero, responsive typography, original PDF software icons, active navigation and category-specific galleries. Source content and all routes remain intact. See docs/ui-ux-audit-v3.md, docs/design-tokens.md and docs/visual-validation.md for evidence and outstanding validation. Reversible baseline checkpoint: tmp/checkpoints/pre-v3.zip.
